## 原惩罚为何可能不足

原 `wheel_airborne=-0.80*missing_contact` 将四轮平均，单轮失去接触只产生 0.20 的奖励密度惩罚。接触使用四个物理样本的最大值，只要 20 ms 内曾经接触，就不会计入离地。原抬轮高度项又允许 15 mm 间隙，轻微跳动较难被覆盖。

## 修改内容

1. 接触使用每个物理样本的法向力，计算四个样本中失去支撑的比例；当前法向力另取明确的瞬时接口，不依赖历史数组的新旧排列顺序。原 Actor/Critic 接触输入和原失败保护不变。
2. 全轮离地系数 0.80 → 6.40、抬轮系数 0.45 → 3.60，均为 8 倍。抬轮项从允许 15 mm、按 40 mm 归一化，逐步切换为允许 3 mm、按 20 mm 归一化；对明显抬高设置有界代价。
3. 前进转向时选取对应的内侧后轮，以软惩罚鼓励持续支撑：轻载/无载 2.40、持续离地 1.20、接触反复切换 0.30、离地时轮心上下运动 0.25。最低软支撑目标为整机重量的 2.5%，约 4.8 N，没有要求四轮等负载或固定关节站姿。
4. 新增项在前 50 次正式更新渐增，保留速度和转向跟踪奖励。转向和前进需求由参考指令门控，避免以实际速度降为零来自动取消目标后轮的惩罚。起始 0.5 s 的落地阶段不施加新接地惩罚。
5. 采样分组改为前进 Q/E 70%（高速 50%、低速 20%），后退组合转向 10%、直行 10%、原地 Q/E 10%。Q/E 对称等比；前进转向由原随机含零的转向命令改为明确保持，部分环境覆盖松开转向键、再次转向和反向转向。

接地、抬轮及内侧后轮识别均采用训练奖励，没有在仿真或测试中写身体/关节状态、附加向下力、锁定站姿或修改动作来伪造接地。

最终检查点 4224，1024 环境同种子评估完成，完整结果已下载到本目录 `contact_comparison.json`。W+Q / W+E 每组各 128 个试验，两版均 128/128 未跌倒。

| 指标 | W+Q：4024 → 4224 | W+E：4024 → 4224 |
|---|---|---|
| 内侧后轮低于接触力阈值的样本比例 | 0.198% → 0.042% | 0.223% → 0.040% |
| 接触切换频率指标 | 0.215 → 0.168 Hz | 0.215 → 0.160 Hz |
| 内侧后轮轮心垂直速度 RMS | 0.00469 → 0.00552 m/s | 0.00479 → 0.00561 m/s |

| 角速度 RMSE | 0.244 → 0.570 rad/s | 0.238 → 0.579 rad/s |
| 横滚峰值统计 | 14.31 → 14.74° | 14.31 → 14.90° |
