源代码、所选日志、机器人资产、参考动作和上述部署权重已经保存在 `server_snapshot/`。文件按服务器根目录的相对路径组织；实际目录名和配置关系见第二份说明。

主原始归档约 312 MB，解压文件约 664 MB；另有约 5.7 MB 补充依赖归档。`verification.json` 与 `dependency_verification.json` 保存本地完整性校验结果。所有源码保留原样，避免破坏 checkpoint 的源码哈希合同。

证据索引：`server_snapshot/portfolio_snapshot_metadata_20261111/evidence.json`；主文件哈希：同目录 `manifest.json`；补充依赖哈希：`dependencies.json`。其中保存了服务器采集时间、部署配置、checkpoint 合同、训练参数、所选末行与控制台尾部。旧文档在 `history/`，须按日期理解。

本包不含完整 Isaac/Python/CUDA 环境、所有历史模型、SSH 私钥或密码。由于源工程存在 Linux 绝对路径，Windows 上可阅读和验证文件；运行仿真应按复现说明准备兼容环境。没有为了整理而停止训练、修改策略或发布到外部网站。
