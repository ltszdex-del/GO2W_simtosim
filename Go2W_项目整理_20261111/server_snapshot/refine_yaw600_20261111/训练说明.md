# 最后一轮转向能力强化

轮驱和抬腿均保留现有组合移动采样、奖励、模型结构、关节限制和线性加减速度。

| 高速模式参数 | 轮驱 | 抬腿 |
| --- | --- | --- |
| 零平移参考角速度上限 rad/s | 4 | 3.14 |
| 满平移参考速度角速度上限 rad/s | 2 | 1.6 |
| 输入角加速度 rad/s² | 4.8 | 4.415625 |
| 制动角加速度 rad/s² | 19.2 | 7.065 |
| 前进 / 后退 / 横移上限 m/s | 3 / 2.5 / 1.3 | 2.3 / 1.5 / 1.3 |
| 追加更新 / 并行数 | 600 / 2048 | 600 / 2048 |

定义 s=min(1, hypot(vx/Vx, vy/Vy))，vx、vy 为平移参考速度；Vx 在前进/后退分别取对应方向的速度上限，Vy 为横移上限。

角速度上限 = 满速上限 + (零平移上限−满速上限) × (exp(−3s)−exp(−3))/(1−exp(−3))。

90% 归一化平移参考速度时，轮驱上限约 2.03666，抬腿约 1.62823 rad/s；满速时精确恢复旧上限。

训练和部署共用 yaw_envelope.py。上限下降先按照制动加速度回落，允许制动期间参考角速度短暂超过新的目标上限，避免瞬间跳变。

K 在高速与低速之间切换：低速模式所有方向线速度上限与整个角速度包络减半，加速度、制动加速度不变。M 切换移动方式时保留高/低速状态；键盘重复按下不会反复触发 K。原生键盘、网页键盘和串流界面按钮均支持 K。

测试环境先上线 K 和包络计算能力，配置继续读取已部署策略的检查点合同。新 4 / 3.14 上限随新训练策略导入而启用，避免旧策略与测试输入合同不一致。

queue_one.py 按种类分别等待 refine_combo300_20261111 对应任务完成，读取其最终存档，核对父代码哈希，保留权重、优化器和随机数状态迁移到独立目录，再通过 64 并行 2 次更新预检，开始 2048 并行的 600 次正式更新。预检结果不进入正式训练链。

预期轮驱从 policy_2699.pt 接续到 policy_3299.pt；抬腿从 policy_9899.pt 接续到 policy_10499.pt。状态和日志放在服务器 /home/ubuntu/Go2W/refine_yaw600_20261111/{wheel,step}_status.json 与 {wheel,step}_supervisor.log。
