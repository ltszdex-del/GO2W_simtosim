# 倒立回站：1秒快速恢复

以 H4099 倒立控制权交接为 t=0，不包含倒立预热。保持原575维观察、16维动作、0.005秒物理步与4次PD子步。

## 目标

- 参考轨迹时长0.65秒；恢复硬截止1.00秒。
- 在截止前连续0.10秒满足四轮接触、后轮已落地、接近U站姿、机身水平且朝向稳定。
- 姿态容差5度、高度误差3厘米、关节RMS误差0.16rad；水平速度<0.20m/s、竖直速度绝对值<0.15m/s、姿态角速度<0.60rad/s、航向误差<0.12rad。
- 不再以历史首次触地速度0.60m/s或历史冲击1.75倍体重阻止成功。允许一定下坠和冲击，不要求无坠落。
- 1秒未完成作为真实终止失败，不能通过超时bootstrap或延长回合获得成功。

## 修改

软触地奖励2→0；触地速度惩罚-2→-0.05；下坠速度-1.5→-0.08；触地前速度-1.5→-0.05；冲击-1→-0.05；力变化率-0.08→-0.01。严重冲击失败阈值3→6倍体重。成功奖励12→20，额外剩余时间奖励最高8；时间代价-0.15→-2/秒。

关节目标速度4→6rad/s、加速度30→45rad/s²；交接起始速度仍限4rad/s，原120ms力矩过渡保留。后腿准备0.90→0.35秒，接触软化0.30→0.15秒，U目标融合0.10→0.06秒。后腿仍主要按真实机身回落角度展开，避免倒立时提前伸展撞轮。

对称、共轴、回落平面、水平朝向、防扭转、前轮移动惩罚保留。头/腹部触地、严重侧翻、关节越限等失败规则保留。没有物理状态瞬移。

## 训练及验收

父策略为straight200的第200轮；先进行0次更新的时序适配测试，再按新目标续训200次PPO更新。仅复用actor权重及其动作分布，critic与优化器重新初始化，避免沿用旧7秒目标的价值估计。训练参数和源码哈希随每个权重保存。

原straight200源码与成果保留。此目录为独立实验。原软着陆阈值字段仅作诊断，require_soft_landing_for_success=False。

实际成功率与用时以固定种子独立无头验收为准，设置1秒截止不代表已经学会1秒动作。
